# Headless examples for 猫里奥 (MaoLiAo)

These programs **do not** open a window and **do not** need EasyX. They exist so the map tables, physics constants, bit flags, and save file can be inspected on Linux or in CI.

They are not a port of the game. Drawing, sound, and the EasyX batch loop stay in `MaoLiAo/`.

## Python

Requires Python 3.10+ (only the standard library).

```bash
# from the repo root
python3 examples/python/cli.py preview --world 1
python3 examples/python/cli.py preview --world 2
python3 examples/python/cli.py preview --world 3 --seed 1
python3 examples/python/cli.py lint
python3 examples/python/cli.py physics-jump --ticks 40
python3 examples/python/cli.py physics-run --hold right --friction T2
python3 examples/python/cli.py decode --keys A+W+J
python3 examples/python/cli.py decode --mask 21
python3 examples/python/cli.py save-read MaoLiAo/gameRecord.dat
python3 examples/python/cli.py extent --world 1
```

Layout:

| Path | Role |
| --- | --- |
| `data/constants.json` | `define.h` tunables |
| `data/tiles.json` | ids 1–14 |
| `data/worlds.json` | authored map / coin / enemy / food tables |
| `python/maoliao/` | library used by the CLI and tests |
| `python/cli.py` | command line |
| `python/tests/` | `unittest` |

World 3 pipes are generated with Python `Random(seed).randrange(a, b)`, which matches the **range** of `rand()%(b-a)+a` but not the MSVC CRT sequence. Use `--seed` to freeze a layout for screenshots and tests.

## C++

```bash
make -C examples/cpp
./examples/cpp/inertia_demo
./examples/cpp/command_flags 21
./examples/cpp/command_flags A+W+J
```

`inertia_demo` prints the same jump table as `physics-jump` (first ticks must match the Python test fixtures). `command_flags` decodes a mask or a key chord.

## Tests

```bash
python3 -m unittest discover -s examples/python/tests -v
make -C examples/cpp test
```

If you edit `MaoLiAo/define.h` or a `createMap` table, update `examples/data/` and re-run both suites.
