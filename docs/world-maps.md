# ASCII 关卡图

`examples/src/world_dump.cpp` 用和 `scene.cpp` 相同的表绘制。只画装进 `map[30]` 的块；丢掉的景色在标题里写 `dropped=`。

图例：`#` 草皮　`=` 地下　`*` 雪　`H` 涩砖　`~` 云或水　`^` 管口　`,` 草　`F` 旗　`o` 金币　`e` 敌人

第三关管道每次 `createMap` 现算，这里只列固定敌人。
