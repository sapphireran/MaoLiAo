# 玩法

三关共用同一套操作，第三关改跳跃和碰撞规则。

## 第一关：草地

地面是草皮（id 1）加土层（id 3），中间一段雪面（id 5）和一小截管道砖（id 6，刹车更快）。空中有四段云（id 2）可以踩。

敌人 10 只，在平台上来回走。金币两处平台顶、一处竖条、一处锯齿。蘑菇在格子 `(14, 5)`，大约第一片云附近。吃到后才能射击。

终点：世界 x 超过 `94 * 32 = 3008` 像素后 `ending = true`，角色锁向右走，飞出窗口右缘算过关。旗在格子 `(101, 7)`。

## 第二关：雪地和浮云

地面改成雪皮（id 5）和雪下（id 4），中间很多单格断桥。上半是一串云台阶，右侧有金字塔状云楼梯。

敌人 6 只，有的站在高云上。金币在最高云和竖井里。蘑菇在 `(39, 3)` 附近偏一点像素。

终点距离 `104 * 32 = 3328`。数据表里旗在 `(111, 1)`，树在 `(4,8)` `(9,8)` `(83,8)` `(89,8)`，但这些块排在第 31 条之后，`MAP_NUMBER = 30` 截断后 **不会被拷进 `map[]`**，所以第二关实际看不到旗和树。详见 level-design。

## 第三关：随机管道

`createMap(3)` 先抽 10 个 `height = random(1, 7)`，再按 `x = i*10 + 10` 摆柱。每根柱子四段：

1. 上口 id 8（倒管道，碰撞按 2× 格）
2. 上管身 id 7
3. 下口 id 10
4. 下管身 id 7

间隙大约三格高，位置随 `height` 变。表后半还有一段云跑道 `{80, 6, id 2, 25 格}` 和旗 `{101, 4}`。后三组柱子在源码里注释掉了，所以只有 7 组管道。

跳跃：第三关按 `W`/`K` 不看 `isFly`，可以连跳。碰到非云砖且没吃蘑菇就死。金币高度也是随机的。蘑菇坐标写成 `{10, 10}` 像素，几乎叠在原点，很容易一开场就捡到——更像占位而不是关卡设计。

敌人 7 只，挂在管道之间的固定格子上，不管这次随机高度是多少。

## 生命与重开

五条命画在 `showDied` 里，用 `role.bmp` 的死亡帧猫头。命数为 1–4 时居中排成一排；`life` 刚减完再画，所以看到的是 **还剩几条**。第五条用完走 `showGameOver`（`home.bmp` 下移一屏的那一截）。

暂停「重新开始」只重建当前关，不把 `life` 加回去。「退出游戏」在暂停里其实返回 `VIR_HOME`，`main` 会回主菜单并重置生命和关卡。主菜单「退出」才是 `exit(0)`。
