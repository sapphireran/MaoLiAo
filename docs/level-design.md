# 关卡数据

地图不是外部文件，而是 `Scene::createMap` / `createCoin` / `createFood` 和 `Role::createEnemy` 里的初始化列表。格子单位：一格 = 32 像素。窗口高 12 格（384 / 32）。

## Map 一行的含义

```text
{ x, y, id, xAmount, yAmount [, u 稍后写入] }
```

`createMap` 按 id 填 `u`，再拷进 `map[i]`。循环条件是 `id ∈ (0, 15)` 且 `i < 30`。列表更长会被静默丢掉。

## 第三关算法

```text
for i in 0..9:
    height[i] = rand() % 6 + 1          // random(1,7)
    x[i]      = i * 10 + 10

每根启用的柱 i = 0..6:
    上口   { x, height-2,     id 8, 1x1 }
    上身   { x, 0,            id 7, 高 max(0, height-2) }
    下口   { x, height+4,     id 10, 1x1 }
    下身   { x, height+6,     id 7, 高 max(0, 6-height) }

收尾:
    { 80, 6, id 2, 宽 25 }   // 云跑道
    { 101, 4, id 12 }        // 旗，无碰撞
```

`i = 7,8,9` 的柱在源码里注释掉。`createMap` 用 `i <= sizeof(m)/sizeof(m[0])`，会多读一格未定义内存，见 study-notes。

敌人固定：`(24,4)← (34,6)→ (37,3)← (43,5)← (63,7)→ (67,8)← (86,5)→`。
